## Phase 1 Setup (Windows)

### Prerequisites
- Python 3.11+ installed (`python --version` to check)
- Git installed

### Steps

Open PowerShell in the `careerai/backend` folder and run:

```powershell
# 1. Create a virtual environment (an isolated Python install for this project)
python -m venv venv

# 2. Activate it (your prompt should now start with "(venv)")
.\venv\Scripts\activate

# 3. Install the dependencies listed in requirements.txt
pip install -r requirements.txt

# 4. Copy the environment template and (for now) leave the defaults as-is
copy .env.example .env

# 5. Start the server
uvicorn app.main:app --reload
```

### Expected output

You should see something like:

```
INFO:     Uvicorn running on http://127.0.0.1:8000
INFO:     Application startup complete.
```

### Verify it works

Open your browser to:
- **http://127.0.0.1:8000/** → should show `{"message": "CareerAI API is running", ...}`
- **http://127.0.0.1:8000/api/health** → should show `{"status": "ok", ...}`
- **http://127.0.0.1:8000/docs** → interactive Swagger API docs (auto-generated by FastAPI)

If all three load, Phase 1 is verified working.

## Phase 2 Setup: Database (Windows)

### Option A — Docker (recommended, easiest)

From the `careerai` root folder (not `backend`):

```powershell
docker compose up -d
```

This starts Postgres in the background, matching the credentials already
in `backend/.env.example` (`careerai`/`careerai`/`careerai` on port 5432).
Verify it's running:

```powershell
docker ps
```

### Option B — Native Postgres install

If you don't want Docker, install Postgres directly:

```powershell
winget install PostgreSQL.PostgreSQL
```

Then, using `psql` (comes with the install) or pgAdmin, create matching
credentials:

```sql
CREATE USER careerai WITH PASSWORD 'careerai';
CREATE DATABASE careerai OWNER careerai;
```

### Apply the migrations (either option)

Back in `careerai/backend`, with your venv already activated:

```powershell
pip install -r requirements.txt
alembic upgrade head
```

### Expected output

```
INFO  [alembic.runtime.migration] Running upgrade  -> 5187e1053666, create users and user_profiles tables
```

### Verify it worked

If you have `psql` available:

```powershell
psql -U careerai -d careerai -c "\dt"
```

You should see three tables: `users`, `user_profiles`, `alembic_version`.

This exact migration was generated and applied against a real Postgres
instance and verified reversible (`alembic downgrade -1` then
`alembic upgrade head` again) before being included here — see
`docs/ER_DIAGRAM.md` for the full planned schema (20 tables total,
built incrementally as each feature phase needs them).

## Troubleshooting

| Problem | Fix |
|---|---|
| `python` not recognized | Reinstall Python from python.org and check "Add to PATH" during install |
| `.\venv\Scripts\activate` gives a script-execution error | Run PowerShell as admin once: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| Port 8000 already in use | Run `uvicorn app.main:app --reload --port 8001` instead |
